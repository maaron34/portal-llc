Five filled stars beside the Google rating line.

## Use it for
- Near the top of web pages, in landing page heroes and in email headers.
- In static ads, five stars sit beside the `ad-proof` line in its own row under the sub line (see Static ads).
- On video end cards, five stars sit directly above the Google rating line (see Video).

## The consumer provides
- The rating text, copied from the claims table in Voice and claims.

## Rules
- Stars are Lucide stars filled with `portal-star`, 22px on the web (16px in review cards), `space-1` apart.
- Always five stars. Never show half stars or a partial count.
- Recheck the review count before using it. It changes.

A 4:3 job photo with the service name and one line of description over a dark bottom gradient, linking to that service page.

## Use it for
- The grid of services on the home page and the services page.

## The consumer provides
- One real photo of that service, the service name and a one-line description from the website.

## Rules
- `radius-lg` corners. The bottom gradient runs from `portal-dark` at 80% to clear; it is the only gradient in the system.
- Title is white, 20px, 700. Description is white at 80%, 14px.
- On hover the photo scales to 105% over half a second. Nothing else moves.
- Use a different photo on every tile.
